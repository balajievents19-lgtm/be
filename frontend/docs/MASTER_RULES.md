# Balaji Royal Events - Master Rules

## Project Goal

Modernize the Balaji Royal Events website using Nuxt 4 while preserving the original Bootstrap design.

---

# MASTER DESIGN

The original Bootstrap ZIP is the MASTER DESIGN.

Never redesign it.

Keep:

- Same layout
- Same section order
- Same navigation
- Same branding
- Same visual identity
- Same user flow

---

# Tech Stack

- Nuxt 4
- Vue 3
- TypeScript
- Nuxt UI 4
- Tailwind CSS 4

---

# Coding Rules

- Use reusable components.
- Keep code production-ready.
- Keep files modular.
- Fix compile errors immediately.
- Fix lint errors in modified files.
- Never duplicate components.

---

# UI Rules

Allowed improvements:

- Better responsiveness
- Better accessibility
- Better performance
- Better animations
- Better typography
- Better spacing

Not allowed:

- Redesign
- Change layout
- Change brand colors without approval
- Change section order
- Replace Bootstrap design with another design

---

# Development Order

1. Header
2. Hero
3. Hero Search
4. Services
5. About
6. Event Categories
7. Gallery
8. Testimonials
9. Latest News
10. Footer

---

# Testing

After every phase:

- Run lint
- Run typecheck
- Run build
- Fix all errors

Project must always remain runnable.
